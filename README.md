# Human Character System witch an example of encapsulation

A small educational **C++** project that demonstrates basic Object-Oriented Programming concepts such as classes, objects, encapsulation, getters, setters, pointers, and separation of code into header and source files.
The program allows the user to create a `Human` character and modify its basic parameters through a console menu.

## Features
The program allows you to:

- Set the character's name
- Set the character's health
- Set the character's damage
- Display all character parameters
- Interact with the program through a console menu
